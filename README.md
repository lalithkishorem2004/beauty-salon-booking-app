# Beauty Salon Booking & Management App

A Flutter-based mobile application developed for Selvi's Beauty Parlour to simplify salon bookings and day-to-day management.

The application provides separate modules for customers and salon owners, allowing customers to explore services and book appointments while owners can manage salon operations through a dedicated dashboard.

## Features

### Customer Module
- User registration and login
- Browse available salon services
- View service details
- Book appointments
- Manage bookings

### Salon Owner Module
- Owner dashboard
- Manage salon services
- View and manage appointments
- Handle appointment requests
- Manage customer information
- Track revenue and business activities

## Services

The application supports different salon services, including:

- Hair styling and treatments
- Hair coloring
- Facial treatments
- Nail services
- Waxing
- Makeup
- Bridal makeup

## Tech Stack

- **Frontend:** Flutter, Dart
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Firebase project configuration

### Installation

1. Clone the repository:

```bash
git clone https://github.com/lalithkishorem2004/beauty-salon-booking-app.git
```

2. Navigate to the project directory:

```bash
cd beauty-salon-booking-app
```

3. Install the dependencies:

```bash
flutter pub get
```

4. Configure Firebase for your project.

5. Run the application:

```bash
flutter run
```

## Firebase Integration

Firebase is used for user authentication and cloud-based data storage through Cloud Firestore.
